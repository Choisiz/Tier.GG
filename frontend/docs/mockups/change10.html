변경 10 목업 매치 행을 펼친 안쪽의 AI 게임 분석

정적 목업입니다(가짜 데이터, 동작 없음). 문장은 실제 LLM 출력(세나 · 딜서폿 · 패배 판)을 그대로 썼습니다. 등급·점수 숫자는 어디에도 만들지 않습니다.

  1. 1. 데스크톱 1280px: 실제 페이지 폭(매치 칸 800px)에서 ① 분석 전 → ③ 결과
  2. 2. 모바일 360px: ① ② ③ 나란히
  3. 3. 상태 모음(매치 칸 800px 폭): ① 분석 전 ② 분석 중 ③ 결과 ④ 템플릿 결과 2종
  4. 4. 오류 모음: 한도 초과, 분석 불가 판, 다시 검색 필요, 잠시 뒤 다시, 그 밖
  5. 5. 분석 대상이 아닌 판(일반·칼바람·15분 미만)을 펼쳤을 때

1. 데스크톱 1280px

왼쪽 280px은 기존 랭크 카드(회색 자리 표시). 오른쪽 매치 칸 800px 안에서 첫 행은 펼침 + 분석 전, 둘째 행은 펼침 + 결과입니다.

2. 모바일 360px

본문 좌우 여백 16px → 내용 폭 328px. 라인전·교전·운영은 세로로 쌓이고, 좋은 점 → 부족한 점 순서로 이어집니다.

3. 상태 모음 (매치 칸 800px)

4. 오류 상태 (펼친 패널만, 800px / 360px)

오류는 결과 자리에 한 줄 안내 + 필요할 때만 버튼. 자동 재시도는 하지 않습니다. 오류도 페이지 안에서 기억하지 않아(결과만 기억) 접었다 펼치면 ① 분석 전으로 돌아갑니다. 단 한도 초과는 페이지 안에서 기억해 다른 판 버튼도 비활성으로 바꿉니다(질문 6).

5. 분석 대상이 아닌 판

일반·칼바람·아레나 또는 15분 미만 판은 버튼을 만들지 않고 이유 한 줄만 보여 줍니다(펼치기 버튼은 모든 행에 그대로, 질문 2).
